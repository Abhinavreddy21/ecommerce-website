# E-Commerce Website

A responsive e-commerce website developed using HTML, CSS, Bootstrap and JavaScript.

## Features

- Responsive design
- Product categories
- Product details page
- Login / Signup page
- Add to Cart option
- Responsive navigation bar
- Mobile, tablet and desktop support

## Technologies Used

- HTML5
- CSS3
- Bootstrap
- JavaScript

## Project

This project was developed as part of my 30 Days Coding Challenge.
